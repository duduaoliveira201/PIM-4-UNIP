B BrewMaster

Aplicativo Flutter para Android

O BrewMaster na palma da sua mão.

Instale o aplicativo Android e acesse o mesmo sistema, com as mesmas telas, conta e dados compartilhados pela aplicação web.

Baixar aplicativo para Android
Como conectar
Conecte o telefone à mesma rede do servidor BrewMaster. Na primeira abertura, informe o endereço de rede mostrado pelo servidor, por exemplo http://192.168.1.10:5180. O servidor deve permanecer ligado. O aplicativo acessa os dados pela API e não conecta ao banco diretamente. O Android pode solicitar autorização para instalar aplicativos baixados pelo navegador.
